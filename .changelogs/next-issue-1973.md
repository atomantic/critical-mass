- **[issue-1973] Fund data-directory resolution moved out of the migration module (internal)** — `resolveFundDataDir`, `getFundDataDir`, `getExchangeDataDir`, `resolveFundPath`, `withFundDataDirOverride`, `PER_FUND_FILES` and `getExchangeKeysPath` now live in `src/fund-paths.js`, so the modules that only need a fund's path no longer import the one-shot v2.0 migration code, and the lazy requires that existed only to dodge that import cycle are gone. Behaviour is unchanged, including which calls create directories; the test suite's data-directory redirection now patches the new module, and a regression test fails if a test patches a path helper on `migration` or the redirection stops working.
