# Release v2.23.0

Released: 2026-07-04

## Highlights

- **Shader-based celestial rendering overhaul.** The admin celestial visualization now renders every body with custom GLSL shaders instead of flat-opacity glow shells and static canvas textures — animated 3D-noise surfaces for stars, a real accretion-disk shader for black holes, and view-dependent rim glow everywhere. It looks dramatically better and runs leaner.
- **Real-time star surfaces.** Suns and hypergiants are drawn with animated fbm-noise shaders (convection / warped gas bands) sampled in object space, so there's no texture UV seam or pole pinching, plus photospheric limb darkening — replacing the pre-baked canvas textures.
- **Physically-flavored black hole.** The three static rings became a single accretion-disk shader with a radial temperature gradient, differential-rotation turbulence streaks, and doppler beaming.
- **Unified rim glow.** A new shared `FresnelGlow` component (additive, depth-write off) provides consistent view-dependent glow across planet atmospheres, star coronas, moon rims, nebula gas envelopes, galaxy cores, and black-hole lensing — replacing every flat back-side opacity sphere.
- **Rendering performance and correctness.** Satellite edge geometry is memoized instead of rebuilt every frame, asteroids dropped four point lights each (and now self-illuminate via a warm emissive ore base), imperatively-built geometries are disposed on unmount, and a galaxy-core depth-write artifact that z-rejected spiral-arm particles is fixed.
- **Reliable local test suite.** `npm test` now runs serially, fixing a Node 24 parallel-test-runner crash that silently dropped ~41 tests and reported a false failure; the full suite is a deterministic 1364/1364.
- **Docs.** Added a `/systems` showcase screenshot to the README.

## Changed

- Shader-based celestial body rendering overhaul across the admin visualization (`admin/src/components/celestial/`):
  - `FresnelGlow`: shared view-dependent rim-glow component replacing all flat back-side opacity spheres
  - Sun & hypergiant: animated 3D-noise surface shaders (fbm convection / warped gas bands) in object space with photospheric limb darkening
  - Black hole: single accretion-disk shader (radial temperature gradient, differential-rotation turbulence, doppler beaming) replacing three static rings
  - Shared `noiseGLSL.js` fbm-noise + surface-vertex chunk; removed now-unused `sunTexture.js` / `hypergiantTexture.js`
  - Warmer ore-vein base color so asteroids self-illuminate

## Fixed

- Galaxy-core glow depth-write artifact that z-rejected spiral-arm particles rendering behind it
- WebGL resource leaks: memoize satellite `EdgesGeometry` (was rebuilt every render), dispose asteroid/satellite geometries on unmount, and drop four point lights per asteroid
- `npm test` now runs with `--test-concurrency=1` to avoid a Node 24 parallel-test-runner IPC deserialization crash (`Unable to deserialize cloned data`) that crashed the `market-data-service.test.js` worker and silently dropped its tests — the file passes in isolation, so this was a runner concurrency bug, not a test-logic failure
