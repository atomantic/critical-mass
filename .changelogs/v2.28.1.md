# Release v2.28.1

Released: 2026-10-25

## Highlights

- **Consistent ladder sizing.** Opt-in auto-aggressiveness now scales ladder rungs as well as reactive entries, with matching preview, automatic placement and rebuild behavior. The capital governor counts held capital and earlier planned rungs so boosts fade as the fund fills.
- **Budget-aware entries.** Ladder allocation respects the remaining deployed-capital limit and available exchange quote balance, reserves unbooked cancel-time fills during rebuilds, and omits scaled rungs below the order minimum. Reduced sizing leaves cash uncommitted.
- **Dependency maintenance.** Updates Three.js to 0.186.1, PostCSS to 8.5.31, the dashboard DOM testing library to 10.4.2, and the container process manager to PM2 7.1.0.

## Upgrade requirements

- Use Node.js 22.12 or newer. For a native installation, run `npm ci`, `npm ci --prefix admin`, and `npm run build`, then follow the coordinated gateway and engine restart order in [UPGRADE.md](https://github.com/atomantic/critical-mass/blob/v2.28.1/UPGRADE.md).
- Auto-aggressiveness remains disabled by default. If enabled, it now affects ladder entries too: boosts can allocate more to nearer rungs and omit later rungs at the budget cap; reductions can leave fewer or no valid rungs when amounts fall below the exchange minimum. Review the ladder preview before rebuilding.
- Disabled auto-aggressiveness, unavailable macro data, an unready score, or stale history preserves baseline ladder sizing.
- No configuration migration is required. The private admin package and Umbrel manifests retain their separate version histories.
