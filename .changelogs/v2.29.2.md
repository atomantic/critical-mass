# Release v2.29.2

Released: 2026-11-08

## Highlights

- **Simple DCA Cost Basis.** Consolidating sells no longer double-counts the consolidated orders' cost, quantity and holdback (consolidated rows stay in the order breakdown but leave the totals), so reserves no longer show a false unrealized loss. BTC whose sell is awaiting placement or failed now counts toward the held totals, shown on a "Not on order" line, and the holdings summary agrees with the Cost Basis tab.
- **Daily DCA schedule display.** The next-trade time and countdown for daily Simple DCA funds now point at 00:00 UTC, when the scheduled buy actually runs, instead of 10:00 UTC. Scheduled-trade retries use the same run-slot boundary.
- **Lighter fund-state snapshots.** Hourly fund-state snapshots keep the UpDown predictor and Sentinel feed poller running (they write nothing the snapshot copies); full daily/manual archives still stop both services. A gateway shutdown during a snapshot now still persists UpDown and Sentinel state, and the snapshot drain no longer waits on scorecard journal appends. Engines are still stopped and restarted around each snapshot, as in v2.29.1.
- **Removed obsolete accounting paths.** The FIFO realized-P&L backfill script (`scripts/backfill-fifo-realized.js`) and its transaction journal are gone; the engine re-derives realized P&L from cycle pairs, so its writes never survived an engine start. A leftover backfill journal or lock no longer blocks startup. Repair scripts stop writing realized-P&L fields the engine discards, and the unused `syncFills` reconciliation routine was removed (`getUnaccountedFills` is unchanged).
- **Admin UI.** Modal dialogs focus their first control when opened. Dependency updates: tailwindcss 4.3.5, react 19.3.1, three 0.187.0, vite 8.3.6, jsdom 31.0.0 (dev; running the admin tests now needs Node 22.22.2+, 24.15+ or 26+, while running the app still needs only 22.12+).
- **Docker image.** pm2 7.1.2 and follow-redirects 1.16.2 in the bundled PM2 runtime.
- **Testing and release tooling.** The test suite runs files concurrently again with per-file isolated data roots and skips fsync on disposable fixtures, and several slow tests now run on a virtual clock. Release verification reads the registry manifest instead of pulling both platform images.

## Upgrade requirements

- No configuration migration is required. Follow the coordinated gateway and engine restart order in [UPGRADE.md](https://github.com/atomantic/critical-mass/blob/v2.29.2/UPGRADE.md).
- Operators who scripted `scripts/backfill-fifo-realized.js` should drop that step; realized P&L is derived automatically.
- The private admin package and Umbrel manifests retain their separate version histories.
